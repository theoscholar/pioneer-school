# Pioneer Service School &mdash; Study Guides

Dyslexia-friendly HTML study guides for all 35 units of the Pioneer Service School
textbook *"Fully Accomplish Your Ministry"* (pt14), grouped by day. Each guide has a
dark theme with a light-mode toggle, adjustable text size, plain-language summaries,
model answers, and reference links that open on the Watchtower Online Library.

Open **index.html** to browse everything.

## Publish with GitHub Pages

1. Create a new repository named **`pioneer-school`** on the account **theoscholar**,
   and upload **all** of these files (keep `index.html` at the top level).
2. In the repo, go to **Settings -> Pages**.
3. Under **Build and deployment -> Source**, choose **Deploy from a branch**.
4. Set the branch to **main** and the folder to **/ (root)**, then click **Save**.
5. After a minute or two your site will be live at:

   **https://theoscholar.github.io/pioneer-school/**

The `.nojekyll` file is included so GitHub serves the HTML exactly as-is.
